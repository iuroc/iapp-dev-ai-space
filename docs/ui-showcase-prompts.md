# 展示向 UI：提示词案例集（静态 + 动效一体）

用途：给「做炫酷 UI 展示」的新会话下发指令。**本文件是可复制的提示词素材，不是读数**；
每次真机效果仍按 `.claude/skills/docs-architecture` 的规矩回填 `docs/evidence.md`。

来源与级别：

- 风格描述（视觉特征、来源系统）来自 2026-10-30 的网络检索（Apple HIG / WWDC25 摘要、
  ColorOS 16 与国产系统评测、Material 3 Expressive 文档页），**级别 ⚠（二手资料）**。
- iApp 落地判断：`✅` 来自 `.claude/skills/iapp-development/SKILL.md` 已验证表；
  `⚠` 是按通用 Android 知识推断、本机未实测；`❓` 完全未验，必须先做探针。
- 版本前提：雷电 14 / API 34（与根 `CLAUDE.md` 的版本政策一致）。

## 0 怎么用（三条）

1. **每条案例都自带静态与动效，不要拆开做。** 一个案例 = 一套静态材质 + 一个「主角动效」。
   只做静态得到一张好看的截图，只做动效得到一段没有质感的动画；两者同行才成立。
   例：底部导航的液态玻璃，必须是「玻璃材质 + 切换 Tab 时液滴滑过去」。
2. **数字才是提示词。** 名词只负责挑方向，效果出不出得来取决于模糊半径、边框 alpha、圆角、
   时长、缓动曲线。案例里这些数字已经填好，换风格时优先改数字，不要只换形容词。
3. **一屏只押一个主角动效**，其余元素降噪（降对比、去装饰）。渐变与模糊滥用会互相抵消。

搭配与禁忌：可以叠（Bento 骨架 + 任意材质、玻璃 + 极光底、3D 卡 + 光扫）；不要叠
**玻璃叠玻璃**、**新拟态 + 霓虹**（一个要低对比一个要高对比）、编辑排版 + 三种以上动效、
同屏超过 2 个字族 / 4 个字号。

用法：把 §2 的环境约束块 + §4 里某个案例整块粘给新会话即可。

## 1 能力红线（改提示词前先看）

| 档 | 内容 |
|---|---|
| 能做 ✅ | 纯色 / 渐变、圆角裁切、`elevation` 与 `setShadowLayer`、`setRotationX/Y` + `cameraDistance`（API 28 已验）、属性动画与插值器、Canvas 自绘（噪点 / 点阵 / 扫描线 / 波形 / 卡面）、`RippleDrawable`（第三参数传圆角遮罩，已验）、触摸跟手、`i.lan(6)` 页面转场（已验） |
| 要绕 ⚠ | 背景模糊 → 把底层画进 `Bitmap` 缩小再放大做预模糊，没有现成 backdrop blur；液态融合 → `BlurMaskFilter` + 颜色阈值，硬件加速下是否生效未测；形状变形 → 两套形状交叉淡入 |
| 先别写 ❓ | 真折射 / 透镜 `RuntimeShader`；Compose 的弹簧物理与真形变（本环境就没有 Compose ✅）；WebView 里的 CSS `backdrop-filter` |

结论：**玻璃类风格在这里是「演出」不是「物理」**——按高光 + 描边 + 预模糊写提示词，
比要求真折射现实得多。另注意 ppt 的 `padding` 按 px 解释，`type=` 含点号要在 `build.xml` 登记。

## 2 环境约束块（每次都要粘）

```text
【环境约束】
- 介质：iApp 工程（.iyu + .mjava），BeanShell 解释执行；没有 Compose / Flutter / Web 框架。
- 界面按 mjava 建树：.iyu 只放一个全屏根 FrameLayout(id=1) 与 <UIEventset> 四个事件；
  子控件、样式、监听器全部在 .mjava 里写；尺寸取 DisplayMetrics（loading 阶段视图宽高是 0）。
- 静态色值、字号写 ppt，渐变 / 圆角 / 描边 / alpha / 阴影 / 动效放 mjava；ppt 的 padding 按 px 解释。
- 图标用 Canvas + Path 现画成 Bitmap，不用 emoji、不引图标库。
- 只有一屏也要能独立运行；入口 src/mian.iyu。
- 工程包名 com.showcase.<slug>，slug 见任务块里的标题。
【交付】
- src/mian.iyu + 一个 .mjava 模块，能直接在本机模拟器跑起来。
- 附动效清单（属性、时长、缓动曲线）与降级方案（哪一项做不出来时换什么）。
```

## 3 时长与缓动（想改节奏就看这里）

| 场景 | 时长 | 缓动 |
|---|---|---|
| 微交互（按压、切换、涟漪） | 100~200ms | `PathInterpolator(0.2, 0, 0, 1)` |
| 元素进出（卡片、弹层、列表项） | 200~300ms | 进 `(0, 0, 0, 1)` 减速 / 退 `(0.3, 0, 1, 1)` 加速 |
| 主角动效 / 整页 | 300~500ms | `PathInterpolator(0.05, 0.7, 0.1, 1)` |
| 弹性 / 果冻 | 300~600ms | `OvershootInterpolator(1.2 ~ 1.5)` |
| 无限循环（呼吸、漂移、粒子） | 4~20s | `LinearInterpolator` + `INFINITE` |

动效只碰 `translationX/Y`、`alpha`、`scale`、`rotation`（走 RenderThread，不触发重绘）；
同屏同时跑 ≤2 条；无限循环在页面 `pause` 事件里停掉，回 `resume` 再开。

## 4 案例（33 条，静态 + 动效一体）

每条标题后的 `slug` 就是包名 `com.showcase.<slug>` 与源目录 `project/com.showcase.<slug>/`，
标题末尾标已建状态。正文是一整块可粘的提示词：静态写材质与尺寸，动效写触发方式、参数与时长。

### A 玻璃与光

#### C01 液态玻璃底部导航 · `liquidglass`（未建：2026-10-31 旧实现已删，需按本案例重做）

```text
【任务】iApp 单页 Demo：一屏可滚动的内容提要 + 底部悬浮玻璃导航条，5 个 Tab（首页 / 发现 / 创作 / 消息 / 我的）。
【静态】导航条宽 = 屏宽 - 24dp、高 64dp、圆角 32dp；填充白 10%；1px 描边（上沿白 40%、下沿白 8%）；
导航条下垫一层「把整页内容预模糊 18px」的位图，让底部内容透出来但看不清细节；主光固定左上。
【动效】切换 Tab 时液滴滑行：选中胶囊从旧 Tab 位滑到新 Tab 位，320ms，OvershootInterpolator(1.1)；
滑行中横向拉长到 1.35 倍、两侧边缘鼓成水滴，落位后 120ms 缩回圆形；
同时目标图标从线框交叉淡入实心，页面内容横向位移 24dp 跟随。
【验收】录屏里液滴是「滑过去」而不是「跳过去」；截图里玻璃边缘比中间亮、内容透出但不可读；
Tab 切换整体 ≤400ms，过程中不允许第二个元素也在动。
```

底部那层模糊用 Bitmap 预渲染（⚠ 没有真 backdrop blur），不要让新会话去写 `RuntimeShader`。

#### C02 磨砂玻璃天气卡 · `frostglass`

```text
【任务】天气首页：三张叠放的磨砂玻璃卡片（今日 / 逐小时 / 空气质量），压在天空渐变上。
【静态】底：天蓝 #7FD8FF → #C9ECFF 竖向渐变，叠 8% 噪点；卡片填充白 14%、圆角 20dp、1px 白 25% 边框；
阴影取天空主色的 20% alpha（不是黑色），偏移 0/8px、模糊 20px；卡片下方的天空做 8px 预模糊。
【动效】滚动联动：页面上滑时三张卡以 0.85 / 0.95 / 1.0 三种速度位移（视差 8~16px）；
卡片随滚动把自身模糊从 8px 收到 0、alpha 从 92% 升到 100%（线性映射滚动位置，不加缓动）；
顶部天空层从 1.0 放大到 1.12。
【验收】滚动时三层有肉眼可见的速度差、卡片越往上越清晰；静止截图上边框比填充亮。
```

#### C03 极光渐变登录 · `aurora`

```text
【任务】登录页：全屏极光渐变底 + 中央大标题 + 一个主按钮 + 一行「游客浏览」次按钮。
【静态】底 #0B1020；四个巨大径向渐变（#22D3EE 青、#A78BFA 紫、#F472B6 品红、#34D399 绿），
半径 ≥ 屏宽 0.9，色带之间不允许出现硬边；整层叠 8% 噪点；标题 44sp 白，副标题 14sp 白 60%；
主按钮全宽减 48dp、高 56dp、圆角 28dp、渐变 #A78BFA → #22D3EE 90°。
【动效】极光常驻漂移：四个色块各自 20s 内平移 24~40px，循环且相位错开，LinearInterpolator；
按下主按钮时极光整体加速到 3 倍并向下涌 8px，按钮缩到 0.96（150ms），松手回弹到 1.0，
并从触点扩散一圈径向高光到按钮边缘（400ms）。
【验收】无操作时画面在动，但看不出循环接缝；按下时是「整个背景在呼吸」，不是只有按钮动。
```

#### C04 液态金属会员卡 · `liquidmetal`

```text
【任务】会员卡页：一张金属质感银行卡居中 + 卡号与额度。
【静态】卡 340×214dp、圆角 18dp；卡面线性渐变 6 个停靠点
（#E8E8EA → #9BA3AF → #FFFFFF → #6B7280 → #D1D5DB），角度 105°；叠 2% 噪点；
卡号等宽 20sp、字距 1.5，持卡人 12sp 大写，文字用深色 #111。
【动效】扫光：每 4s 一道宽 40% 屏宽、白 45% → 透明的渐变条从左划到右（1.6s，Linear）；
入场时卡片从 -24dp 落位（320ms，Overshoot 1.2），同时 rotationX 从 12° 回正到 0（cameraDistance 9000）。
【验收】扫光是「一道光带过表面」，不是整卡变亮；回正过程文字不抖。
```

#### C05 光场控制中心 · `osglow`

```text
【任务】控制中心：深色底 + 四个琉璃质感的圆形磁贴（Wi-Fi / 蓝牙 / 亮度 / 音量）。
【静态】底 #101322；磁贴直径 = (屏宽 - 3×16dp) / 2，填充白 8%、1px 白 18% 描边；
图标用同色 22% 底；每个磁贴背后压一团同色径向光斑（半径 = 磁贴 1.6 倍，中心 alpha 35%，边缘到 0）。
【动效】点开磁贴：光斑从 1.0 扩散到 2.2 倍并淡到 0（500ms，Emphasized），
磁贴从圆形挤成圆角矩形（两套形状交叉淡入，240ms），图标由线性变实心；关闭时反向。
【验收】光是从图标背后「透出来」而不是叠在上面；开 / 关各 500ms 内完成。
```

光斑用 Canvas 径向渐变画进 Bitmap（✅），不要用 elevation 阴影冒充。

### B 材质

#### C06 新拟态计算器 · `neumorphism`

```text
【任务】计算器：显示屏 + 4×5 键盘（0-9、四则、等号、清除）。
【静态】底 #E9EDF3；按键 72dp、圆角 20dp，凸起 = 左上白 90% 光 + 右下 #C3C9D4 阴影（偏移 8px、模糊 16px）；
```

#### C07 黏土打卡 · `claymorphism`

```text
【任务】习惯打卡页：一张软糖质感卡片 + 一个 160dp 进度环，点一下完成今日打卡。
【静态】底 #FFF4EC；卡片填充 #FFD9C0、圆角 = 高度 40%；两个内阴影（上白 30%、下 #E8A47F 20%）
+ 一个外阴影（#B26A3D 15%，偏移 0/12px、模糊 24px）；进度环宽 14dp。
【动效】打卡瞬间：圆环从当前角度补到 100%（600ms，Emphasized），一颗同色圆球沿环跑一圈后
砸进圆心，砸落时挤扁到 1.16 : 0.86 再回弹（240ms，Overshoot 1.4）；卡片整体下沉 2px 再起。
【验收】有软糖「压一下再弹回」的手感；环补满与球落位是同一动作的两段，不要各走各的。
```

#### C08 果冻空气感音乐首页 · `frutigeraero`

```text
【任务】音乐首页：天空渐变底 + 三个漂浮玻璃气泡 + 一张半透明卡片 + 播放按钮。
【静态】底 #7FD8FF → #E8FBFF 竖向渐变；气泡 = 径向渐变球体 + 左上白色高光点 + 边缘 1px 亮线
（直径 96 / 140 / 72dp）；卡片白 55%、圆角 24dp；点缀色 #5CE1A6；标题字距 -0.5。
【动效】气泡常驻漂浮：各自 8~14s、相位错开，纵向正弦位移 ±12dp、scale 1.0 ↔ 1.04；
点播放时三个气泡向按钮汇聚并缩到 0.4 消失（420ms），1.2s 后从按钮位置重新胀出（Overshoot 1.2）。
【验收】漂浮能看出是循环但接缝不突兀；汇聚与胀出用同一组缓动。
```

#### C09 千禧风播放器 · `y2k`

```text
【任务】Y2K 风格播放器：chrome 渐变标题 + 像素边框 + 一个可拖动音量旋钮。
```

### C 版式与结构

#### C10 便当格健康总览 · `bento`

```text
【任务】健康总览：4 列便当格（步数 2×1、睡眠 1×1、心率 1×1、饮水 1×2、训练 2×1）。
【静态】间距 12dp、圆角 24dp；格子只用 1×1 / 2×1 / 1×2 / 2×2 四种；每格 = 主数值 32sp + 标签 12sp
+ 同色 10% 底（步数绿、睡眠紫、心率红、饮水蓝）。
【动效】入场逐格错峰：每格延迟 60ms，从下方 16dp 淡入（280ms 减速），主数值同步从 0 滚到目标值
（等宽字体，600ms，与入场同时结束）；点某格时它放大到铺满屏（320ms Emphasized），其余格淡到 0。
【验收】滚数字不引起宽度跳动；错峰是「一波推过去」，不是同时出现。
```

#### C12 编辑排版长文 · `editorial`

```text
【任务】长文阅读页：大标题 + 首字下沉正文 + 一段引文 + 页码，作为「低动效对照组」。
【静态】12 栏网格；标题 76sp、行高 0.95、字距 -1；正文 15sp、行高 1.6；1px #E5E5E5 hairline 分隔；

【验收】整页安静，唯一动的是首次入场；它衬托其余案例有多花。
```

```text
【任务】卡包：三张银行卡叠放，左右滑动切换，当前卡显示额度。
```
