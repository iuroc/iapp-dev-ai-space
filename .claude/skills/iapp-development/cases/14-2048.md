# 14 经典 2048（实战：滑动 + 方向键 + 动画 + 持久化）

日期：2026-10-26　环境：Android 9 (API 28)　iApp 5.0.1013

## 目标

用现有 KB 从零做一个完整可玩的 2048，同时反向验证 SKILL/docs 的缺口。
验收项：滑动、方向键、三件套动画、分数/最高分、胜负、杀进程恢复。

## 分工

| 层 | 内容 |
|---|---|
| ppt | 控件树、尺寸、颜色、字号、`layout_weight`、弹层 |
| mjava | 棋盘数据、合并算法、动态瓦片、动画、输入、存档 |
| `i.sss` | 跨 call 状态（board/score/best/won/over/busy/pending/side） |

## 关键写法

- 键盘：`<eventItme type="downkey">call(null,"mjava","game.keyCode", st_kC)</eventItme>`
- 滑动：`boardFrame.setOnTouchListener`（匿名接口），24dp 阈值 + 主导轴
- 动画：`ObjectAnimator` 平移/缩放，`postDelayed(匿名 Runnable)` 分段收尾
- 输入锁：`g.busy` + `g.pending`，动画结束后执行最后一个待处理方向
- 动态视图：`setTag("tile:"+idx)`，跨 call 用 tag 查
- 存档：`activity.getFilesDir()/game2048.save`，每次有效移动落盘
- 自检：`loading` 里跑 8 个纯逻辑用例，`G2048 TEST ... PASS`

## 遇到的问题

1. **`touchmonitor` 参数不明**：改用 mjava `setOnTouchListener`，一次通过。
2. **方向键拿不到键码**：反编译发现 `downkey` 参数名是 `st_kC`，传进 mjava 后方向键可用。
   再把 `setOnKeyListener` 注释掉做隔离复核，方向键仍全部生效 → 单条 `downkey` 就够。
3. **动画收尾没有监听器**：`AnimatorListenerAdapter` 是抽象类不能用，改 `postDelayed`。
4. **动画期间连按**：加 `busy`/`pending`，一次只处理一个方向。
5. **动态视图跨 call 找不到**：用 `setTag` + 遍历子视图。
6. 首次启动 `best` 为空：`or0()` 统一兜底，避免 `Integer.parseInt("")`。
7. 棋盘格子算错：`cellSize = (side - 2*pad - 3*gap)/4`，一开始漏了第三个 gap。
8. 结束状态杀进程重开：棋盘恢复但弹层没恢复，`over=1` 又挡住输入，像卡死。
   补了 `layout()` 末尾的 `restoreOverlay()`，按棋盘重算胜/负并显示弹层（2026-10-26 补，未复测）。

## 复用的 KB 结论

- 入口、`loading`/`loadingComplete`、`clicki`、`downkey`
- 单模块 mjava + `i.sss` 跨 call
- 匿名接口实现可用，回调能调模块方法
- `ObjectAnimator` + `postDelayed`
- `getFilesDir()` 持久化
- 应用内自检
- 动态 addView + tag + bringToFront
